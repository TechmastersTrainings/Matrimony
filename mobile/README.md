# Christian Matrimony Mobile App (Flutter)

Production-ready Flutter & Dart mobile application initially serving Christian families in **Bidar, Karnataka, India**.

## Architecture

- `lib/core/config/`: Environment loading and configuration
- `lib/core/network/`: HTTP client abstraction and health diagnostics
- `lib/core/theme/`: Custom application theme and color palette
- `lib/routing/`: Named route navigation (`AppRouter`)
- `lib/screens/`: UI Screens (`SplashScreen`, `HomeScreen`)
- `lib/widgets/`: Reusable UI components
- `lib/models/`: Data models placeholder
- `lib/services/`: Services placeholder

## Run Locally

```bash
flutter pub get
flutter run
```
